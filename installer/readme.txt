eKavach CBAC Auto-Filler
========================
1. Start the app from the Start menu.
2. First run: click "License / About", copy your Machine ID, send it to the vendor, paste the key you receive and press Activate.
3. Enter your portal username/password, set "Max patients", press Start.
   Tip: run one patient first and confirm it in the portal.

Requires Google Chrome or Microsoft Edge.
patients_example.csv shows how to give per-patient answers.
Settings/licence are kept in %APPDATA%\EkavachFiller.
